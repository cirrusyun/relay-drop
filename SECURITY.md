# Security policy

Please do not publish exploitable security issues in a public issue.

Use GitHub's **Security → Report a vulnerability** flow in this repository. Include the affected version, reproduction steps, impact, and any suggested mitigation. Reports made through that form are private to the repository maintainers.

Relay Drop is designed for a single owner or a small trusted group. Everyone who knows the shared login can read the clipboard, download files, rename files, and delete files.
